Цей проект містить реалізацію 5 класів відповідно до завдань.

## Завдання 1: Клас BankAccount

**Атрибути:**
- `account_number` - номер рахунку
- `balance` - баланс рахунку

**Методи:**
- `deposit(amount)` - додає суму до балансу
- `withdraw(amount)` - знімає суму з балансу (з перевіркою достатності коштів)

### Приклад використання:
```python
account = BankAccount("1234567890", 1000)
account.deposit(500)      # Додає 500
account.withdraw(300)     # Знімає 300
account.withdraw(2000)    # Помилка: недостатньо коштів
```

## Завдання 2: Клас Car

**Атрибути:**
- `make` - марка автомобіля
- `model` - модель автомобіля
- `year` - рік випуску

**Методи:**
- `get_info()` - повертає рядок у форматі "[рік] [марка] [модель]"

### Приклад використання:
```python
car = Car("Toyota", "Camry", 2022)
print(car.get_info())  # Виведе: 2022 Toyota Camry
```

## Завдання 3: Клас Employee

**Атрибути:**
- `name` - ім'я працівника
- `position` - посада працівника
- `salary` - заробітна плата

**Методи:**
- `get_salary_info()` - повертає рядок у форматі "Заробітна плата [ім'я]: [заробітна плата]"

### Приклад використання:
```python
emp = Employee("Іван", "Програміст", 50000)
print(emp.get_salary_info())  # Виведе: Заробітна плата Іван: 50000
```

---

## Завдання 4: Клас Rectangle

**Атрибути:**
- `width` - ширина прямокутника
- `height` - висота прямокутника

**Методи:**
- `calculate_area()` - обчислює площу (ширина × висота)
- `calculate_perimeter()` - обчислює периметр (2 × (ширина + висота))

### Приклад використання:
```python
rect = Rectangle(5, 10)
print(rect.calculate_area())       # Виведе: 50
print(rect.calculate_perimeter())  # Виведе: 30
```

## Завдання 5: Клас Product

**Атрибути:**
- `name` - назва товару
- `price` - ціна товару
- `quantity` - кількість одиниць товару

**Методи:**
- `calculate_total_price()` - обчислює загальну вартість (ціна × кількість)
- `display_info()` - виводить інформацію про товар

### Приклад використання:
```python
prod = Product("Ноутбук", 15000, 2)
print(prod.calculate_total_price())  # Виведе: 30000
prod.display_info()  # Виведе всю інформацію про товар
```
